```
📋 보드 sync · <제목> · 실측 <MM/DD HH:mm>
실측 <N>건 · 실패 <M> · Jira <J>건(MCP)

단계 변화
- #813 월렛 결제 게이트웨이: 리뷰 대기 → 리뷰 중 (타인 코멘트 1)
- feature/…-batch-poll: 착수 전 → 작업 중 (원격 브랜치 생김)

실측 실패
- 보안성 검토 신청 (ISE-1624): Jira 403 — 마지막 값 09/18 14:02 "정책진단 대기" 유지

제안 (승인하면 반영)
- "admin gateway" 카드: 브랜치 feature/…-admin-gateway 의 PR #842 를 pr 필드에 채울까요?

미등록 PR (카드 없음 — 행을 정해주면 만듭니다)
- #845 feature/ACME-1234-partner-refund · draft · "환불 분기"
```

- 변화가 없으면 "단계 변화 없음" 한 줄. 빈 절은 통째로 뺀다.
- 카드 이름은 제목 그대로, PR은 `#번호`로. 시각은 로컬.
- 미등록 PR은 **보고만** 한다. 사용자가 행·열을 정해 주면 채팅 편집 규칙으로 만든다.
