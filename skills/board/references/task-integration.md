# 작업 수명주기 스킬과 붙이기

이 스킬은 단독으로 완결되지만, 티켓 단위 런북·QA·리포트를 관리하는 스킬(예: `/task`)이 있으면 세 지점에서 부른다.
아래는 그 스킬 쪽에 넣을 지시문의 예다(경로·문서 이름은 그쪽 규약을 따른다).

| 시점 | 부르는 것 | 런북 쪽 변화 |
|---|---|---|
| 킥오프(런북 생성 직후) | `/board new <티켓 제목> --file <런북 디렉터리>/board.json --repo <리포> --ticket <키>` | 런북 상단 현황 절에 보드 링크. 매트릭스는 만들지 않는다 |
| 갱신(런북 update 첫 단계) | `/board sync --file <…>/board.json` | 현황 절은 TL;DR 3줄 + 보드 링크만. "내가 할 일" 목록은 보드의 「내 몫」 필터가 대신한다 |
| 마무리(wrap) | `/board sync` 마지막 1회 → 아티팩트 제목을 `🗄️ 보관 \| 보드 · <제목>`으로 재게시(같은 URL, `icon` `archive`) | 런북 보관과 같은 날 |

- 런북의 "이어받기·사람 몫·결정 대기·외부" 같은 **서사형 목록은 런북에 남긴다** — 카드 필드로 담기지 않는 커밋 순서·조건이 거기 있다.
- 기존 런북에 매트릭스가 있으면 `/board import`로 옮긴 뒤 매트릭스를 지우고 링크만 둔다.
- 보드 파일(`board.json`)은 런북과 같은 디렉터리에 두어 git 히스토리가 함께 남게 한다.
